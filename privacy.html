Privacy Policy

Last updated: November 1, 2026

This policy covers "goodpartsonly uploader", an internal tool used only by the owner of the Good Parts Club channel.

What the tool accesses

With the owner's permission, the tool uses Google OAuth to access the owner's own YouTube account in order to upload videos the owner made and to read the channel's basic information and analytics.

How data is used and stored

Access tokens are stored only on the owner's own computer. No data is sold, shared with third parties, or used for advertising. The tool does not collect data from any other person.

Google API Services

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The tool uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions.
